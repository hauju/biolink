About

Full-Stack Rust Developer & Solopreneur, based in Germany 🇪🇺

I'm Hauke Jung — a full-stack Rust developer and solopreneur. I build small, focused tools — mostly in Rust — with a bias toward simple infrastructure, observability, and developer experience.

When I'm not shipping code, I'm usually outside on a trail. I like work that stays close to the fundamentals: small surface area, sharp tooling, and things that keep working without much fuss.

What I build

Most of my time goes into a handful of products:

Infra.page — hosting, analytics, errors & deploys in one dashboard SeggWat — feedback collection for indie projects & small teams Oxidt — my tech blog on Rust, software & indie hacking Hike & Code — where hiking meets software engineering

Alongside the products, I publish libraries and developer tools as open source — embedded-hal sensor drivers, a Dioxus docs kit, testing helpers, and more. See the open-source work →

Stack

Day-to-day, I reach for Rust for backends, drivers, and CLIs; Dioxus for fullstack web UIs; Tailwind CSS + DaisyUI for styling; and self-hosted infrastructure wherever it makes sense.
